# Portfolio Site Plan

## Pages
1. Home (`index.html`)
2. Projects/Work (`projects.html`)
3. About/Contact (`about.html`)

## Intended Color Palette
- Navy blue for headers and navigation
- Medium blue for links and future buttons
- Very light blue for the page background
- Light gray for content sections

## Intended Font Choices
- Headings: Georgia, serif
- Body text: Arial, sans-serif

## Assignment Notes
No CSS is included yet. The HTML files focus on structure and meaning.
All three pages use the same navigation with relative links.
